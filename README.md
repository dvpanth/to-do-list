# To Do List
A simple command line to-do list built with Python.

## Features:
- Add task
- View task (completion status)
- Mark as complete
- Delete task
- Validate task

The initial version of the to-do list has no further details within the elements other than whether it is completed or not. Planned improvements include:
- Adding task descriptions
- Persistent tasks using JSON
- Adding due dates
- Refactoring for efficiency
